# Task 19 — Demo Video Script

**Target length:** 3–5 minutes. Record the real application after it runs successfully.

## Suggested recording sequence
1. **Introduction (15–20 sec):** Say the project name, purpose, and MERN technologies.
2. **Architecture (20–30 sec):** Briefly show the architecture diagram and explain React → Express API → MongoDB.
3. **Login and dashboard (30 sec):** Sign in with a demo account and show the dashboard.
4. **HR workflow (45–60 sec):** Show employee management, leave review and announcement features that are actually working.
5. **Employee workflow (45–60 sec):** Sign in as an employee and show the available self-service features.
6. **Database/API explanation (30–45 sec):** Show the model file or API structure without exposing secrets.
7. **Conclusion (10–15 sec):** Summarize working features and disclose any limitations.

## Recording checklist
- Close unrelated tabs and notifications.
- Use demo data only; never show real personal information.
- Do not display `.env`, passwords, JWTs or connection strings.
- Keep the text readable and move the pointer slowly.
- Verify audio and playback before sharing.
- Save the final video in a suitable format or upload it to a sharing service and test access permissions.
- Add the video link to the README after the video exists.
