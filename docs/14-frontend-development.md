# Task 16 — Frontend Development and Explanation

## Frontend responsibilities
- Render the sign-in page and dashboard.
- Display navigation and features appropriate to the signed-in user.
- Send authenticated API requests through the API helper.
- Display employee, leave, attendance, announcement and training information.
- Collect form input and show success/error feedback.
- Provide a layout that works at common desktop and mobile widths.

## Demonstration checklist
1. Open the frontend URL.
2. Sign in using a demo account.
3. Navigate through each visible module.
4. Try the relevant forms and confirm that changes persist after refresh when expected.
5. Sign out or change accounts and confirm role-specific access.
6. Resize the browser to inspect responsive behavior.

Do not claim a screen or action works until you have tested it. If a feature is incomplete, note that limitation honestly.
